# Nodecraft

ブラウザだけで動作するワークフローエディタ。Vite / React / TypeScript 製です。

## 開発

```sh
npm ci
npm run dev
npm test
npm run build
```

## 操作

左の＋からノードを追加。出力の丸から入力の丸へドラッグして接続します。空白をドラッグすると範囲選択、Shift + クリックで複数選択、スペース + ドラッグまたは左の移動ツールでパンします。ホイールでズーム、右下のボタンで倍率調整と全体表示ができます。複数選択時の詳細パネルからグループを作成し、グループの見出しをドラッグすると全体が移動します。接続線を選択して削除できます。Ctrl/Cmd + Z と Ctrl/Cmd + Shift + Z で履歴を操作できます。

作業は localStorage に自動保存されます。JSON の読み込みは全体を置き換えます。Markdown 出力には検証結果も含まれます。開始ノードは削除・複製できません。

## 設計

共通スキーマの `nodes`, `edges`, `groups` を単一のグラフとして保持します。接続時はポートと存在を確認した後、接続先から深さ優先探索を行い、接続元に到達する場合に循環を拒否します。出力ポートは1本までです。インポート時には同じルールで接続を順に検証します。履歴はグラフ全体のスナップショットで最大100操作を保存し、ドラッグは完了時に1操作として確定します。外部のグラフ描画ライブラリを使わず、DOM と SVG で描画しています。React のみで状態管理することで依存を抑えています。

GitHub Pages は Actions ワークフローを用意しています。リポジトリの Settings → Pages でソースを GitHub Actions に設定してください。Vite の base は `/nodeeditor-codex/` です。
